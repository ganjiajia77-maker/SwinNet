# H0 surface-only + decoder global soft gate

Based on 599a410. The H0 model is constructed for shared initialization and then pruned to a surface-only backbone: encoder road priors A1/A2, H0, S/C/D, decoder structure gates, H3 fusion and auxiliary losses are disabled. Surface focal BCE + 0.5 Dice is retained. Decoder feature X and detached preliminary surface probability P replace the original H0 and C inputs to the sparse global module. Candidates are top 256 P pixels followed by FPS to at most 32 nodes. Node self-attention uses four heads and positional bias; the grid cross-attends to them. The 9x9 neighborhood soft gate is P + 0.2*(1-P)*maxpool(P), with alpha = 0.05*tanh(raw_alpha), initial alpha 0. The gate and node selection are detached. No explicit connection supervision is used.

Massachusetts protocol: native 1500, one random 512 crop per image per epoch (shared epoch across persistent workers), 512/256 sliding validation/test, FP32, no EMA, batch 2 and accumulation 1, 80 epochs, seed 1234, ImageNet LR 5e-5 to 5e-6 and new weights 2e-4 to 1e-5, warmup 10. Validation every 5 epochs selects best by F1 at 0.5; the validation threshold sweep selects the final threshold by global IoU. Topology uses the unified v7 raster-derived graph protocol: TOPO seed 0.002/step 0.0002; deterministic sampled APLS at most 150 controls per graph, TLTS 200 paths; four CPU workers. These graph scores are not directly equivalent to scores on official vector GT.

The module sees one 512 tile at a time, and has no evidence-guarantee for long gaps. No full 512 GPU smoke or actual data experiment has been run locally.
