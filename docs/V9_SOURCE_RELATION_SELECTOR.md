# V9 source-relation selector

This experiment starts from the ORIGINAL direct V9 stage_D/best.pth, not its
G-benefit continuation or failed candidate-path branch. Original core files and
their checkpoint hashes are untouched. BASE/Q3 remain strictly frozen/eval.
Scalar mode delegates to the unchanged original forward, with bitwise equality
tested. New checkpoints have a distinct version and strict module/identity/config
loading; only the new selector is initialized on top of the original V9.

## Compute path

Original H/H3 projections and unaggregated eight-direction pair features are
reused. Each shared edge scorer separately reads nine32-channel blocks:
actual Fp,Fq,Fq-Fp,Fp*Fq, original raw directional pair embedding, original local
context, short-edge midpoint and two side-flank features. It also reads16 scalar
channels: Up,Uq,Uq-Up,Rp,Rq,Support_p,Support_q,Wd,P0p,P0q,Qp,Qq,dy,dx,rate,V.
The midpoint/flank features are at the actual H work scale; they do not magically
restore native image details that the frozen representation has already lost.
Native labels, however, are never generated by resizing GT to that grid.

Each edge is scored BEFORE aggregation. A separate small stay score competes
with those eight scores in one nine-way softmax. Invalid out-of-image sources
are masked; low R or W is a soft input rather than a hard permission rule.
There are no remote sources and exactly three iterations in the actual original
signed direction order: left/right, up/down, NW/SE, NE/SW.

SourceSupport remains R+(1-R)*clamp((U-P0)/(1-P0),0,1), exactly as in original V9.
The original W-weighted source mass V and original rates input are preserved.
The original mixed M is still computed as legacy_m for reference, but is NOT
the new update target. Diagnostic m is the conditional source mean AFTER choice,
so alpha*(m-U) agrees with the actual update; it is not an input to selection.
Eight actual source_transport_delta terms are saved separately. With nine
weights a0,a1..a8 summing to1:

`transport = rate_transport * sum_d a_d*(U_source_d-U)`

`proposal = .2*A*rate_proposal*(B-U)`

`anchor = rate_anchor*(P0-U)`

`U_next = U + transport + proposal + anchor`

There is NO additional scalar G, A or V multiplication on the new transport.
The convex rate budget keeps U bounded without a probability clamp hiding an
invalid update. SourceSupport, neighbours, rates and choices are recomputed
each step. Original logit composition consumes the actual final U3.

Original scalar G is computed only to retain legacy reference/interfaces, and
changing its unused heads cannot affect source-mode P1 (tested). The wrapper
uses a temporary forward hook: the small old three-step scalar loop is computed
then discarded in source mode. This costs extra downstream computation but
avoids refactoring the checkpoint-sensitive core. No second backbone forward
is required. Forward hooks are always removed, including on exceptions.

## Native relationship labels

Each relation is the ACTUAL adjacent work-grid source, mapped to native512 crop
coordinates using the measured integer H stride (normally4). Labels are built
from native GT road pixels using bounded local reachability inside a radius1.25
pixel corridor around that short edge, with a1-native-pixel endpoint tolerance.
An endpoint tolerance disk that touches multiple locally disconnected native
roads is ambiguous and ignored, rather than snapping to either road at will.
GT pixels are not dilated to bridge missing pixels. A curved GT path that fits
only a modestly wider local corridor is ignored, rather than made a hard
negative. Distant connected-component
membership cannot validate a local shortcut. Native junctions, crop boundaries
and ambiguous/unsupported endpoint cases are ignored. Labels are proxies for
short local road continuation, not formal graph/overpass annotations. No explicit
dataset uncertainty annotation is available here; these local heuristics cannot
identify every ambiguous overpass or incorrect GT annotation.

No predicted endpoint discovery is needed. Relations with model-visible P0/R/U
or Q evidence are considered; correct native road continuation is positive.
Local blocked road pairs, background extensions and background responses are
negative categories, without claiming perfect parallel-road/bridge semantics.
GT is used only in native label generation and losses, never in inference,
source choice or dynamics state updates. No BCE-benefit L_G labels are reused.

Training matching is within image, step, actual direction and action sign
(including a separate near-zero-action group), then potential/source-confidence
bins. Direct relation BCE supervises shared edge logits, with balanced class
means and equal step means. A correct relationship is NOT a demand for positive
or large transport; Uq-Up and the final Surface loss determine its state effect.
Stay has no invented GT class and is not trained by the fixed-input edge BCE.
It starts near90% stay and is learned by actual repair losses in stage B.

## Stages and validation

Stage A (default5 epochs): all original V9 modules frozen, only the small shared
edge scorer trains on original V9 features/states. No L_seg/L_cont update to
the original network and no path/benefit loss. Full14-image val audit uses all
512/256 tiles with unique work-cell ownership. Baseline per-source weight is
the real original `G*W*shift(SourceSupport)/source_mass`; compare it to edge
logits and actual nine-way choice weights on IDENTICAL relation rows.
Report natural and matched ROC/PR-AUC, wrong acceptance at equal correct
acceptance (.8/.9), step/direction strata, counts and image-bootstrap intervals.
This is relationship acceptance, not helpful-action BCE acceptance.

The explicit val screen requires better edge discrimination on both populations,
no worse actual choice ranking at those working points and at least one natural
image-bootstrap interval below zero. If it fails, `all` saves the reason and
stops WITHOUT launching20 repair epochs. This does not prove absence of useful
features; inspect labels/matching/features. Empty training-label epochs fail.

Stage B (default20 epochs, only after Stage A passes): freeze original V9; train
selector edge and stay using ORIGINAL `L_seg+.2*L_cont` through the new update.
No L_G, candidate path losses or extra transport supervision. Re-audit fixed
original V9 relations after training to check whether discrimination was lost.
Val-only threshold curves include own thresholds, same threshold, fine matched
Recall/area, fixed P0.45/206 reference gaps, approximate APLS, closure/bridge
proxies, addedTP/FP and short components. actual_source_relations.csv additionally
decomposes actual per-source weights/updates by supported/blocked/uncertain
native relationships and step. These are relationship proxies, not claims that
every negative signed update is harmful. None is called a formal graph metric.

Optional `joint` is separate and never auto-started: after repair inspection,
unfreeze existing visual/R/W/rates/B/A and feature/pair projections with small
LR; BASE/Q3 and unused old scalar gate heads remain frozen. No new feature
encoder or multiscale source set is introduced. It continues from repair best.
The frozen-stage input replay cannot by itself establish a causal joint benefit.

Same physical batch2, accumulation1, FP32, no EMA, native1500 random512 once per
image, seed1234, train-only augmentation. Optimizer/RNG/epoch checkpoints allow
restart. Intermediate epoch audits save statistics; raw relation score NPZ is
saved for the best audit rather than storing huge frozen feature caches.
Test data are not accessed. Original V9 is an already-trained reference; the
new staged training is not a same-budget pure-loss ablation.

Run `bash scripts/run_v9_source_selector.sh all` for smoke -> Stage A -> fixed
relation audit -> conditional Stage B -> val comparison. `results` prints the
compact reports; `relation` stops after scoring/audit. `repair`, `audit`, `val`
and explicitly separate `joint` are available. The exact BASE/Q3 dependencies
are resolved/strictly checked from original V9, not path placeholders.
